# Review checklist

- Approved section order preserved.
- Existing production App remains untouched.
- WhatsApp number centralized.
- No API secret is introduced in frontend code.
- AI entry point does not expose model credentials.
- Social profile placeholders are not presented as verified URLs.
- Customer testimonials do not invent named people.
- Newsletter does not claim to persist data yet.
- Legal footer includes the official SIC destination.
- Responsive rules cover desktop, tablet, and mobile breakpoints.
