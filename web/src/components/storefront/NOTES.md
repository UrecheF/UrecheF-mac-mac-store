# Implementation safeguards

- `main` is untouched.
- Existing catalog/API behavior remains untouched.
- Existing storefront is not yet replaced or duplicated.
- WhatsApp number is centralized in `src/config/store.js`.
- Placeholder social URLs are deliberately non-navigational until official profile URLs are verified.
- Newsletter is presentation-only until a subscriber backend is selected.
- Testimonials use generic copy; no fabricated named customer identities are shown.
- The SIC link points to the official authority site.
- Mac Advisor teaser currently routes to WhatsApp; the protected AI service will be wired in a separate step with usage limits.
